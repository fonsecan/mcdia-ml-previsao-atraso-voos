# Runs históricas importadas

Este diretório preserva as 16 runs reconstruídas a partir do resultado agregado da validação progressiva de 2024–2025. Os artefatos foram movidos para cá quando a sequência de runs reproduzíveis foi reiniciada em `runs/000001`.

As métricas, configurações reconstruídas e catálogos são úteis para consulta, mas não constituem evidência de uma execução plenamente reproduzível: não foram registrados na origem os hashes do dataset, commit, ambiente, logs, previsões, relatórios por classe ou matrizes de confusão.

Não crie nem execute novas runs neste diretório. Use `runs/` para todas as execuções novas.
